# Grill Me

Use `grilling` when installed; it owns the shared interview behavior. This name
remains available for existing invocations.

Standalone fallback: inspect supplied context and discoverable facts, then ask
one unresolved decision question at a time with a recommended answer. Reuse
accepted decisions. Finish with accepted choices, assumptions, and remaining
blockers. Do not start implementation unless that work was also authorized.
